An AI-powered assistive device combining **embedded electronics, computer vision, OCR, voice interaction and AI** into a compact system.

```text
             📷 CAMERA
                 │
                 ▼
        ┌─────────────────┐
        │     ESP32       │
        │  Embedded Core  │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │   AI / VISION   │
        │     ENGINE      │
        └────────┬────────┘
                 │
       ┌─────────┼─────────┐
       ▼         ▼         ▼
     OCR      NAVIGATION   AI
       │         │         │

                 ▼
```

### ✨ Features

* 👁️ AI vision
* 🔎 OCR
* 🌐 Translation
* 🧭 Navigation assistance
* 🗣️ Voice interaction
* 🙂 Face recognition
* 🚨 SOS functionality
* 📷 ESP32 camera system
