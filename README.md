## 🚀 FEATURED PROJECT

### 👁️ NavEye V1 — Your AI Guide Beyond Sight

**NavEye V1** is an ESP32-based assistive device concept combining AI, computer vision and voice interaction to help users understand their surroundings.

**Core capabilities**

- 🤖 AI-powered visual understanding
- 🔎 OCR for signs, labels and documents
- 🌍 Translation
- 🧭 Navigation and obstacle guidance
- 👤 Face recognition
- 🎙️ Voice interaction
- 🆘 SOS concept
- 🔊 AI responses through audio

**Repository:**  
👉 [View NavEye V1](https://github.com/kartik231024-hub/NavEye_V1---Your-AI-Guide-Beyond-Sight)
